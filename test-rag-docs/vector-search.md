# 向量数据库与语义搜索技术

## 向量数据库概述

向量数据库专门存储和检索高维向量数据，是 RAG 系统和语义搜索的核心基础设施。

### 主流向量数据库

- **PGVector**：PostgreSQL 扩展，将向量作为一等公民存储，支持 IVFFlat 和 HNSW 索引
- **Milvus**：云原生向量数据库，支持十亿级向量检索
- **Qdrant**：Rust 实现的高性能向量搜索引擎
- **Weaviate**：内置向量化和混合搜索能力
- **Chroma**：轻量级向量数据库，适合原型开发

## Embedding 模型

Embedding 模型将文本映射为固定维度的稠密向量，语义相近的文本在向量空间中距离更近。

常用的中文 Embedding 模型包括：

- **BGE-M3**：BAAI 的多语言模型，支持 1024 维向量输出
- **text2vec-large-chinese**：中文语义向量模型
- **M3E**：Moka 开源的中文 Embedding 模型

## 语义搜索 vs 关键词搜索

| 维度 | 语义搜索 | 关键词搜索 |
|------|---------|-----------|
| 匹配原理 | 向量余弦相似度 | BM25 / 倒排索引 |
| 同义词 | 自动识别 | 需要词典 |
| 精确匹配 | 可能漏掉 | 精准 |
| 跨语言 | 支持 | 不支持 |
| 计算开销 | 高（GPU 推理） | 低 |

## 混合搜索策略

实际应用中通常结合两种搜索方式：向量检索捕捉语义相关性，关键词检索保证专业术语精确命中。通过 RRF 或加权求和融合两路结果，取长补短。
