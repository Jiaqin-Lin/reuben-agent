# RAG 检索增强生成技术详解

## RAG 是什么

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与文本生成相结合的技术架构。它先根据用户问题从知识库中检索相关文档片段，再将检索结果作为上下文提供给大语言模型，使其生成更准确、更可靠的回答。

## 文档分块策略

分块（Chunking）是 RAG 系统的基础环节，直接影响检索效果。

### 固定大小分块

按字符数固定切分，实现简单但容易切断语义。通常设置 overlap 来缓解边界问题。

### 递归分块

按段落→句子→固定窗口的层级递归切分，优先在自然边界断开。

### 语义分块

计算相邻句子的 Jaccard 相似度或 embedding 余弦距离，在语义边界处切分。

### 结构分块

利用文档的标题层级（H1-H6）作为自然分块边界，保持章节完整性。

### LLM 分块

让大模型阅读文本后输出断点位置，质量最高但成本也最高。

## 混合检索与融合

### 向量检索

将文档 chunk 通过 Embedding 模型转换为稠密向量，查询时计算余弦相似度。擅长捕捉语义相关性，但可能漏掉精确关键词匹配。

### 关键词检索

基于 BM25 或倒排索引的关键词匹配。擅长精确匹配和专业术语，但无法理解同义词和语义变体。

### RRF 融合

Reciprocal Rank Fusion 将多路检索结果按排名倒数加权合并：`RRF_score = Σ(1 / (K + rank_i))`，K 通常取 60。无需调参，对排名差异鲁棒。

## 检索质量优化

### 查询改写

用户自然语言问题往往包含口语化表达和代词指代。通过 LLM 改写为更适合检索的查询文本，同时检测并拆分多问题为独立子查询。

### 证据门控

对检索结果设置最低相似度阈值和相对分数下限，过滤弱相关噪声，减少无关上下文对 LLM 生成质量的干扰。

### 父块提升

检索时用小粒度 chunk 保证命中精度，返回时将 chunk 替换为其所属的父级段落完整文本，确保 LLM 获得充足上下文。

### 重排序

用 Cross-Encoder 模型对融合后的候选结果二次精排，在更细粒度上评估查询与文档的相关性。
